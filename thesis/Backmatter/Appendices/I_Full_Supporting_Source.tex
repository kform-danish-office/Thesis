\chapter{Complete Supporting Software Source}
\label{app:full-supporting-source}

These are the complete project files for the controller build,
browser interface, software tests, and thesis data processing.
Appendix~\ref{app:software-tools} explains how they work together.
The browser files include the monitoring dashboard, calibration and setup controls, and resonant-tank calculator.

The two complete firmware versions are in Appendix~\ref{app:full-embedded-source}.
