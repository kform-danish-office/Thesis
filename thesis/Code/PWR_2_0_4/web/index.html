V2 switching/carrier timingV2 / F410 only

Adjust the V2 / STM32F410 gate switching carrier and complementary-gate deadtime. The LC components set the natural resonance; EN burst frequency is a separate setting.

Connect V2 / STM32F410 with compatible PWR-2.0.4 or newer firmware.

Requested timing

Whole numbers: 500,000–2,000,000 Hz and 20–200 ns. Timer ticks quantize both values: the period has an even tick count; deadtime rounds up. At 100 MHz, ticks are 10 ns and carrier steps are about 20 kHz near 1 MHz. Some frequency/deadtime pairs are rejected.

A change to actual timing clears all three learned load profiles and tuned calibration values in RAM. Physical load resistances are retained. Recalibrate as needed, then use Save to device to retain timing and calibration together. Applying timing keeps output OFF.
